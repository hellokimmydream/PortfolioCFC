# Portfolio
Portfolio avec base de donnée SQL, représentant mes résultat en apprentissage

# Lancer le projet
1. Dans le dossier Uwamp, double clique sur Uwamp.exe
2. Démarrer le service Uwamp sur la fenetre du programme
3. Dans l'encadré My Web, cliquer sur : Navigateur wwww
4. Dans la fentre du navigateur, dans Virtual Host : cliquer sur portfolio_site
